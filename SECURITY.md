# Security Policy

## Supported versions

Candidait is in initial development. Security updates currently target the latest code on the `main` branch only.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older commits or branches | No |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Report it privately to the repository owner through GitHub. Include:

- A clear description of the vulnerability and its potential impact.
- Reproduction steps or a proof of concept.
- Affected files, versions, or environments.
- Any suggested mitigation, if known.

You should receive an acknowledgement within five business days. The maintainers will investigate, keep you informed of material progress, and coordinate disclosure after a fix is available. Please allow a reasonable remediation period before sharing details publicly.

Do not access, modify, or retain data that does not belong to you while researching a vulnerability.
