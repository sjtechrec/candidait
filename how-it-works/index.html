Marketplace boundary

Shared infrastructure. Separate permissions.

The same evidence model can power candidate tools and employer workflows without making private candidate work visible across the marketplace.

Candidate workspace

  • Private source documents and drafts
  • Evidence confirmation and corrections
  • Target-specific resume versions
  • Explicit visibility controls

Employer workspace

  • Verified organization access
  • Public jobs and hiring teams
  • Submitted or discoverable profiles only
  • Transparent reasons with human review
